# 先生時短AI v12

GitHub Pagesにそのまま配置できる静的サイトです。外部AI APIは使用せず、ブラウザ内テンプレートで授業案・板書案・ミニテストを生成します。

## 確認方法

1. `index.html` を開く
2. 5年 → 算数 → 割合 → ミニテストを生成
3. 「作り直す」「コピー」「端末内に保存」を確認

「マイ授業デスクに保存」はブラウザのlocalStorageに保存され、「PDFでローカル保存」はB4縦の問題ページと答え・解説ページを分けた印刷画面を開きます。各ページは中央で縦2分割し、問題は左に問題1〜3、右に問題4〜5、答え・解説も同じ2段組で配置しています。問題ごとの余白を揃え、練習問題の右上に点数欄を置いています。印刷画面で用紙サイズがB4になっていることを確認し、「PDFとして保存」を選択してください。
