# 先生時短AI v5.1

国語・算数・理科・社会・英語の5教科に対応したビジュアルMVPです。

## 使い方
1. `index.html` をブラウザで開きます。
2. 教科を選びます。
3. 単元を選びます。
4. 「やさしい / 標準 / チャレンジ / 特別支援配慮」を切り替えます。
5. 授業案・板書・図/挿絵・活動・ミニテスト・つまずき対応を確認します。

## 今回の主な更新
- 5教科対応
- 教科別UI
- 教科ごとの重点機能
- レベル切替
- ビジュアル板書
- 図・挿絵エリア
- ミニテストの答え＋生徒向け解説
- お気に入り・最近使った
- 利用分析
- 教科別機能マトリクス
- スマホ用下部ナビゲーション

## 注意
これはUI/UXとサービス構造を確認するための静的MVPです。
正式版では Next.js + Supabase + AI API + 管理画面へ移行する想定です。
教材名・単元名はデモ用を含み、正式公開前に学習指導要領・採用教科書・著作権・利用規約を確認してください。
