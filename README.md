# 先生時短AI v12

GitHub Pagesにそのまま配置できる静的サイトです。外部AI APIは使用せず、ブラウザ内テンプレートで授業案・板書案・ミニテストを生成します。

## 確認方法

1. `index.html` を開く
2. 5年 → 算数 → 割合 → ミニテストを生成
3. 「作り直す」「コピー」「端末内に保存」を確認

「マイ授業デスクに保存」はブラウザのlocalStorageに保存され、「PDFでローカル保存」はB4縦の問題ページと答え・解説ページを分けた印刷画面を開きます。印刷画面で用紙サイズがB4になっていることを確認し、「PDFとして保存」を選択してください。
