# SchoolPilot v17

GitHub Pagesにそのまま配置できる静的サイトです。すらぷり、ちびむすドリル、ぷりんと365などの公開教材の構成を参考にした類題を、ブラウザ内テンプレートで授業案・板書案・小テスト・復習テストとして生成します。問題文の転載ではなく、学習項目・難易度・問題形式を参考にしたオリジナル問題です。出題結果には参照資料へのリンクを表示します。

## 確認方法

1. `index.html` を開く
2. 学年 → 教科 → 教科書の出版社 → 単元の順に選ぶ
3. 5年 → 算数 → 東京書籍 → 割合 → テストを確認
4. 「作り直す」「コピー」「端末内に保存」を確認

トップ画面の単元一覧は、文部科学省の教科書制度と、各出版社が公開している単元・年間指導計画を参考に同梱しています。学校の採択版や年度によって単元の名称・順序が異なる場合があります。

「マイ授業デスクに保存」はブラウザのlocalStorageに保存され、「PDFでローカル保存」はB4縦の問題ページと答え・解説ページを分けた印刷画面を開きます。各ページは中央で縦2分割し、問題は左に問題1〜3、右に問題4〜5、答え・解説も同じ2段組で配置しています。問題ごとの余白を揃え、練習問題の右上に点数欄を置いています。印刷画面で用紙サイズがB4になっていることを確認し、「PDFとして保存」を選択してください。
